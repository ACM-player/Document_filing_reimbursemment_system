# ADR-0002：统一且不可变的文件资产

- 状态：接受
- 日期：2026-08-10

## 背景

项目档案和报销附件都需要上传、类型检查、SHA256、软删除、恢复、审计和备份。如果两套业务各自实现物理文件逻辑，长期容易出现行为和权限不一致。

## 决策

使用统一 `FileAsset` 保存物理文件元数据。`Document` 与 `ExpenseAttachment` 通过外键引用文件资产。文件入库后不可覆盖；替换创建新资产。

V1 不根据相同 SHA256 自动共享物理文件。重复检测只提示或记录，避免引用计数和删除生命周期尚未成熟时造成数据丢失。

## 后果

- 上传与完整性校验只实现一次；
- 数据库和媒体备份更容易形成一致清单；
- 需要明确临时文件、数据库事务和原子移动失败时的补偿流程；
- 后续如需去重，必须新增 ADR 和完整的引用生命周期测试。
