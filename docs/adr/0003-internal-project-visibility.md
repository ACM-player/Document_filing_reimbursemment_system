# ADR-0003：内部默认可读与受限项目访问申请

- 状态：接受
- 日期：2026-08-10

## 背景

课题组经常临时安排未参与项目的成员整理、汇总或查找历史材料。如果所有项目档案都要求预先加入项目，管理员需要频繁调整成员，降低档案平台的实际可用性；但完全无差别开放又无法处理确有保密要求的项目。

## 决策

项目使用两级可见性：

- `INTERNAL`：默认值，所有 `ACTIVE` 已登录课题组成员可以查看和下载；
- `RESTRICTED`：仅系统管理员、项目成员和获批申请人可以访问。

内部可见性只授予只读和下载权限，不授予上传、修改、删除、分类或成员管理权限。受限项目支持填写用途的访问申请，由项目负责人、项目管理员或系统管理员审批；批准后默认创建可到期的 `VIEWER` 项目成员关系。

未获授权的正常成员只能看到受限项目的最小目录信息：名称、编号、负责人、状态和申请入口，不能看到项目描述、文件或关联报销。批准申请不得降低用户已有的更高项目角色。

V1 不实现文档级可见性例外。确需单文件保密时，应将项目设为受限或在后续 ADR 中设计文档级访问规则。

报销附件不属于内部可见项目档案。项目负责人和项目管理员可以查看其他成员的关联报销概要，但不能查看其发票、支付截图和其他报销附件。

## 后果

- 临时整理事务无需管理员逐一添加普通项目成员；
- 项目角色继续控制写入和管理权限，不与内部只读权限混淆；
- 敏感项目需要负责人主动选择 `RESTRICTED`；
- 系统必须提供清晰的可见性提示和访问申请审计；
- 访问申请、临时成员到期和用户离组需要统一失效处理。
