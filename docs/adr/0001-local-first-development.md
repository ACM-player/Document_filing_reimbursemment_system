# ADR-0001：本地优先开发与个人试运行

- 状态：接受
- 日期：2026-08-10

## 背景

前期业务流程、权限粒度和数据字段仍可能调整。立即部署到实验室服务器会提前引入网络、TLS、运维和迁移成本，并增加错误数据被多人使用的风险。

## 决策

先在开发者本机完成开发、自动化测试和个人试运行。开发与测试均以 PostgreSQL 为数据库，不使用 SQLite 作为便捷回退。Nginx、TLS、监控和服务器自动启动延后到服务器阶段。

代码从第一天保持分环境配置、可迁移路径、权限检查、审计接口和备份恢复设计。

## 后果

- 可以更低成本地调整需求和模型；
- Docker 与生产 Linux 的真实运行验证暂时不能视为完成；
- 开始录入真实数据后，本机故障会成为风险，因此必须启用备份；
- 服务器部署前需要单独进行 Linux、存储权限、TLS 和联合恢复验收。
